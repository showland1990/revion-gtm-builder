# Value proposition that converts

Build from specific audience, trigger, painful job/problem, desired outcome, alternative, differentiated mechanism and proof.

Create a one-line value proposition, supporting proof and persona variants where buyer/user differ.

Prefer concrete outcomes over faster/easier/smarter. Never claim unsupported results.
