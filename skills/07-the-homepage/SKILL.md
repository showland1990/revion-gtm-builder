# The homepage

Render strategy; do not invent it.

Flow:
1. Audience/problem/outcome headline
2. Why now / stakes
3. Product mechanism
4. Relevant proof
5. Use cases/outcomes
6. Objection handling
7. CTA matched to readiness

For developer products preserve a fast path to docs, quickstart, repo or trial. If positioning is weak, route upstream.
