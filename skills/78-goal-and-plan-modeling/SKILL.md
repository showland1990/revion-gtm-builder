# Goal and plan modeling

> A revenue plan should show exactly what has to be true for the target to happen.

## Start from target

Break revenue target into:
- existing recurring revenue
- renewals
- expansion
- new logo
- self-serve
- enterprise

## Work backward

For each component define:
- bookings needed
- ACV
- wins needed
- opportunities needed
- qualified conversations/PQLs needed
- traffic/accounts needed
- creation timing
- headcount/capacity

## Scenario planning

Build:
- base
- upside
- downside

Vary:
- win rate
- ACV
- pipeline creation
- sales cycle
- retention
- expansion
- paid spend
- rep ramp
