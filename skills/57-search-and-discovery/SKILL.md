# Search and discovery

> Search strategy begins with user intent and useful answers, not keyword volume.

## Discovery surfaces

Map where the ICP discovers solutions:
- web search
- AI/search assistants
- GitHub
- package registries
- docs
- Stack Overflow / technical communities
- Reddit/HN
- marketplaces
- vendor directories
- integration ecosystems
- review sites

## Intent architecture

Build clusters around:
- problem
- job
- category
- implementation
- integration
- alternative
- comparison
- error/troubleshooting
- template/example
- pricing/security

## Page/asset quality

A useful page should contain:
- clear answer
- firsthand expertise
- concrete examples
- proof
- technical depth appropriate to audience
- updated information
- next action

Do not mass-produce thin pages.

## Developer-specific discovery

For developer products:
- README
- repo description/topics
- docs IA
- package metadata
- integration docs
- example repos
- issue/search discoverability

## Measurement

Track:
- qualified organic visitors
- target queries/topics
- activated users from organic
- PQL/opportunities
- content-assisted conversions
- branded demand lift

Avoid ranking reports detached from business outcomes.

Write organic discovery plan into `content-engine.md`.
