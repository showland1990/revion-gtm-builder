# Attribution reporting

> Attribution should change budget or strategy decisions, not merely produce a credit-allocation chart.

Read `attribution-model.md`.

## Reporting layers

### Acquisition
- first known source
- self-reported source

### Product
- signup source
- activated source
- PQL source

### Pipeline
- opportunity creation source
- meaningful journey touches
- account engagement

### Revenue
- won revenue by source
- influenced revenue with confidence

## Confidence

Every influenced number should state:
- high / medium / directional
- logic used
- known blind spots

## Program decisions

For each program answer:
- what job was it supposed to do?
- what leading signal changed?
- what downstream result changed?
- what would likely have happened without it?
- increase / maintain / change / stop?
