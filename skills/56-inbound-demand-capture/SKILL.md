# Inbound demand capture

> Demand capture does not create interest from nothing. It converts intent that already exists.

## Intent map

Classify demand:

### Problem intent
"how to solve X"

### Category intent
"X software/tool/platform"

### Alternative/comparison intent
"X vs Y", "alternative to X"

### Integration intent
"X + Y", ecosystem/marketplace

### Product intent
brand, pricing, docs, security

### Purchase intent
demo/contact/enterprise/security/procurement

## For each intent define

- audience
- likely stage
- landing asset
- message
- proof
- CTA
- self-serve or sales path
- measurement

## Route by readiness

Examples:
- technical problem → guide/docs → try
- comparison → comparison/use-case → try/evaluate
- pricing → pricing → self-serve or contact
- enterprise/security → trust center/contact → sales
- integration → integration page/marketplace → install

## Lead capture rule

Do not gate information by default simply to manufacture leads.
Gate when the exchange creates real user value:
- benchmark report
- diagnostic
- tool
- event
- template
- high-value research

Measure downstream quality, not form fills.
