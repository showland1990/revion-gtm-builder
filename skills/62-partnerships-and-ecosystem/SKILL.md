# Partnerships and ecosystem

> A partnership is only strategic if both sides have a concrete reason to keep investing.

## Partnership types

- technology/integration
- cloud/marketplace
- channel/reseller
- services/SI
- community
- content/co-marketing
- data/research
- strategic alliance

## Evaluate

For each partner:
- shared ICP
- complementary value
- distribution
- technical value
- commercial incentive
- credibility
- implementation effort
- sales conflict
- data/privacy considerations

## Mutual value

Write:
- what we give
- what they give
- who owns execution
- joint customer outcome
- success metric

## Partner funnel

Track:
- sourced users/accounts
- activated users
- influenced opportunities
- partner-sourced pipeline
- revenue
- retention/expansion
- integration adoption

## Output

Write ecosystem priorities and partner scorecard.
