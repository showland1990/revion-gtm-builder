# Marketing ops and handoffs

> Good operations make customer state legible across teams. Bad operations create competing definitions of the same human and account.

## Canonical objects

Align:
- anonymous visitor
- person
- product user
- workspace
- account
- lead/contact
- PQL/PQA
- marketing-qualified state if used
- opportunity
- customer
- expansion opportunity

## Lifecycle definitions

Every state needs:
- objective definition
- entry event
- owner
- next action
- SLA if human
- exit event
- suppression

## Qualification

Do not create MQL purely from content-score accumulation.

Qualification should combine where relevant:
- fit
- intent
- behavior
- timing
- product value
- explicit request

## Routing

Define:
- inbound sales request
- PQL
- enterprise product intent
- target-account engagement
- partner referral
- customer expansion
- support vs sales ambiguity

## Campaign taxonomy

Standardize:
- source
- medium
- campaign
- content
- offer
- segment
- region
- partner
- event

Keep taxonomy usable, not encyclopedic.

## Consent and preferences

Respect:
- unsubscribe
- channel preference
- privacy obligations
- regional requirements
- customer/support context
