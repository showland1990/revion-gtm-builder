# Routing Smoke Tests

1. `We're pre-revenue and don't know our customer.` → start-here / talk-to-users / who-is-this-for.
2. `We have 8,000 signups but almost no revenue.` → acquisition quality → activation → retention → monetization → PQL.
3. `We need to double pipeline.` → do not default to outbound; inspect demand/product signals/targeting/funnel math.
4. `Our biggest enterprise deal keeps slipping.` → opportunity-inspection.
5. `Marketing shipped loads of content but pipeline is flat.` → revenue-marketing-review.
6. `Nobody trusts the forecast.` → revops-strategy / stage definitions / data / forecast.
7. `What should we work on next?` → strategy-and-roadmap with one company constraint.
