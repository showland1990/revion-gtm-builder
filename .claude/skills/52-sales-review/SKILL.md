# Sales operating review

> Review the revenue system, not just this week's deals.

## Scorecard

Review:
- target accounts worked
- qualified conversations
- opportunities created
- pipeline created
- pipeline coverage
- stage conversion
- win rate
- ACV
- sales cycle
- slippage
- no-decision rate
- forecast accuracy
- expansion pipeline

## Diagnose in order

1. Is there enough qualified account coverage?
2. Are conversations converting to real opportunities?
3. Are opportunities progressing?
4. Where do they stall?
5. Is the issue product, value, proof, stakeholder alignment, process or commercial?
6. Which losses are controllable?
7. What did product-led signals contribute?
8. Which segment/source has the best economics?

## Learning loops

Feed back:
- objections → messaging/product marketing
- lost-deal causes → positioning/product
- PQL false positives → PLG scoring
- security blockers → enterprise readiness
- pricing resistance → packaging/pricing
- successful business cases → proof library
- champion patterns → account/persona model

## Output

Update:
- sales scorecard
- sales model
- GTM context evidence
- roadmap

Choose one primary sales constraint.
