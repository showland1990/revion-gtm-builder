# Executive GTM dashboard

> Executives need a small number of diagnostic metrics that lead to action.

## Dashboard sections

### Revenue
- ARR/MRR
- new logo
- expansion
- churn/contraction
- NRR/GRR

### PLG
- qualified acquisition
- activation
- retention
- PQL/PQA
- self-serve conversion

### Marketing
- qualified demand
- pipeline created
- CAC/payback
- major program signal

### Sales
- pipeline created
- coverage
- win rate
- ACV
- sales cycle
- slippage

### Forecast
- commit
- best case
- gap

### Customer
- renewal risk
- expansion
- adoption/health

## Rules

- show trend
- show target
- show segment/source where useful
- annotate data confidence
- highlight current constraint
