# Security and procurement

> Enterprise deals often die from process, not product. Surface the process early enough to manage it.

## Discover early

Ask:
- security review required?
- SOC 2 / ISO requirements?
- data classification?
- data residency?
- DPA?
- subprocessors?
- SSO/SCIM?
- audit logs?
- on-prem/VPC?
- legal review?
- vendor onboarding?
- procurement threshold?
- insurance?
- accessibility?
- AI/model/data policy?

Do not promise compliance you do not have.

## Readiness library

Maintain:
- security overview
- architecture/data flow
- subprocessor list
- privacy answers
- certifications
- incident response
- retention/deletion
- AI/model usage disclosure
- standard DPA/MSA
- insurance
- support/SLA
- accessibility where relevant

## Deal process

For each opportunity capture:
- requirements
- owner
- submitted date
- blockers
- exceptions
- target completion

## Risk classification

Red:
requirement cannot be met

Amber:
can be met with work/exception

Green:
standard supported response

Escalate product/legal decisions explicitly.

## Output

Update opportunity risk and reusable enterprise-readiness gaps.
