# Time to first value

Acquisition into a broken first run loses users faster.

Choose one path to first value. At each step log the user's question, frustration and barrier.

Apply the weekend test: a motivated user should get something real working without human rescue.

Define first meaningful win, time-to-value, top drop-offs and the event/metric for first value. Do not confuse signup/setup with activation.
