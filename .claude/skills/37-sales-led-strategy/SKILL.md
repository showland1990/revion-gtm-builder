# Sales-led strategy

> Sales-led growth is not "hire reps." It is a system for finding the right accounts, creating or capturing urgency, helping a buying committee reach conviction, and converting value into an organizational purchase.

Read first:
1. `docs/gtm-cofounder/gtm-context.md`
2. `docs/gtm-cofounder/foundation-review.md`
3. `docs/gtm-cofounder/gtm-roadmap.md`
4. `docs/gtm-cofounder/plg-model.md` and `pql-model.md` if product-led signals exist
5. existing sales process, pipeline definitions and CRM notes if provided

Use `founder-led-sales` for the earliest selling motion. Use this skill when the company needs a repeatable sales operating system.

## Decide whether sales-led is justified

Evaluate:
- target ACV
- implementation complexity
- number of stakeholders
- security/procurement burden
- need for business case
- product evaluation complexity
- executive sponsorship
- customer-specific rollout
- strategic account value
- expansion potential

Do not add humans merely because the company wants "enterprise."

## Define the commercial architecture

Explicitly choose:
- inbound sales
- outbound sales
- product-led sales assist
- partner-led
- account-based
- hybrid

Define how each source enters the same opportunity process.

## Canonical sales states

A recommended starting model:

```text
Target account
→ Engaged
→ Qualified conversation
→ Discovery complete
→ Validated opportunity
→ Evaluation / solution fit
→ Business case / decision
→ Procurement / legal / security
→ Commit
→ Closed won/lost
→ Adoption / expansion
```

Change labels if needed, but every stage needs objective entry and exit criteria.

## Opportunity unit

For every real opportunity require:
- account
- compelling problem
- quantified consequence
- trigger / compelling event
- champion
- economic buyer
- decision criteria
- decision process
- competition / status quo
- next step + date

If too many are missing, it is not yet a forecastable opportunity.
