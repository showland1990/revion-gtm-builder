# Conversion architecture

> Conversion optimization is helping the right person take the right next step, not maximizing one button click.

## Map conversion paths

By state:
- problem aware
- solution aware
- evaluating
- product ready
- enterprise ready

By motion:
- self-serve try/install
- product demo/sandbox
- docs
- contact sales
- technical evaluation
- pricing
- security/procurement

## Page decision framework

Each page needs:
1. audience
2. intent
3. problem
4. promised outcome
5. evidence
6. objections
7. primary CTA
8. secondary CTA
9. downstream success metric

## Proof hierarchy

Use the strongest relevant proof:
- direct customer outcome
- recognizable peer
- usage/adoption
- benchmark
- technical evidence
- security/compliance
- testimonials

## Optimize downstream

A CTA test is successful only if it improves or protects:
- activation
- qualified pipeline
- paid conversion
- retention

Do not optimize demo bookings that become unqualified meetings.

Write conversion map and experiment backlog.
