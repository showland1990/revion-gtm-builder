# Expansion marketing

> Expansion starts from realized customer value plus a credible next use case.

Read PLG expansion signals and sales/customer context.

## Expansion triggers

- seat/team growth
- usage growth
- new project
- new business unit
- new geography
- new integration
- enterprise/security need
- champion promotion
- executive initiative
- renewal
- adjacent use case

## Expansion hypothesis

For each:
- current realized value
- next problem/use case
- beneficiary
- buyer
- proof
- product signal
- account signal
- best owner
- CTA

## Plays

- in-product expansion
- lifecycle education
- CSM value review
- executive business review
- account-based campaign
- champion enablement
- cross-team workshop
- reference from internal peer

## Guardrail

Never push expansion before the existing implementation is healthy.

## Output

Add expansion marketing model and qualified expansion signal definitions.
