# Forecasting and commit

> Forecasting is an estimate with visible assumptions, not a ritualized confidence score.

## Components

Forecast:
- new logo
- self-serve/product-led
- expansion
- renewal
- churn/contraction

## Forecast categories

Define objective rules:
- Pipeline
- Best case
- Commit
- Closed

## Inputs

Use:
- stage
- historical conversion
- stage age
- next step
- close-date history
- compelling event
- procurement/legal status
- champion/buyer
- renewal health
- expansion signal

## Forecast math

Build:
- bottom-up opportunity forecast
- cohort/velocity forecast
- capacity/creation forecast

Compare them.

## Risk

Track:
- slippage
- concentration
- large-deal dependency
- new-rep dependency
- renewal concentration
- product-led conversion changes

## Output

Write:
`docs/gtm-cofounder/forecast.md`
