# Weekly operating review

> Weekly reviews should resolve uncertainty and unblock execution, not narrate dashboards.

## Agenda

1. Revenue/forecast delta
2. Primary GTM constraint
3. Leading indicators
4. PLG changes
5. Marketing/demand changes
6. Pipeline/deal risks
7. Customer/expansion risks
8. Data quality issues
9. Decisions required
10. Owners/actions

## Rules

- discuss exceptions, not every metric
- distinguish signal from noise
- assign decisions, not vague follow-ups
- update roadmap if priority changes
- update GTM context if learning changes strategy
